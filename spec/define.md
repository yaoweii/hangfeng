# 数据规范

## 1. 目的

本文档定义当前项目中平面板、曲面板及返回曲线数据的最小必要规范。

目标是统一输入输出格式，去掉旧文档中的冗余字段，后续设计、实现、测试都以本文档为准。

## 2. 通用约定

### 2.1 坐标约定

- 平面板输入边界使用局部坐标系。
- 平面板通过变换矩阵可转换到全局坐标系。
- 曲面板三角面片按全局坐标系给出。
- 返回值中的 `xyz` 和切线方向统一按全局坐标系表达。

### 2.2 曲线编码

当前项目统一使用 `rxy` 或 `rxyz` 描述曲线。

- `rxy` 单点格式：`[r, x, y]`
- `rxyz` 单点格式：`[r, x, y, z]`

### 2.3 头元素约定

`rxy` / `rxyz` 数组的第 `0` 项为头元素，不表示几何点。

- 第 `0` 项的 `r` 表示当前曲线控制点总数，包含头元素本身。
- 第 `0` 项的坐标值不参与几何计算，推荐填 `0`。
- 实际几何点从第 `1` 项开始。

即：

- 若数组第 `0` 项为 `[n, ...]`
- 则有效几何点范围为第 `1` 项到第 `n - 1` 项

### 2.4 段定义约定

对任意实际几何点 `i`，其定义范围为 `1 <= i < n - 1`：

- 若第 `i` 项的 `r = 0`，表示 `i -> i + 1` 为直线段。
- 若第 `i` 项的 `r` 为其他普通数值，表示 `i -> i + 1` 为圆弧段，`r` 即该圆弧半径。
- 若第 `i` 项的 `r = +2` 或 `r = -2`，表示该位置存在曲线截断或断开。

### 2.5 截断约定

- `abs(r) == 2` 统一表示曲线存在截断或断开。
- 当前阶段仅使用“存在截断”这一语义，不额外区分 `+2` 和 `-2` 的业务含义。
- 若后续需要区分截断方向，再单独扩展，不在当前规范中定义。

## 3. 平面板定义

平面板仅保留以下 3 类数据：

1. 变换矩阵
2. 边界线
3. 偏移

### 3.1 平面板结构

```text
PlanePanel
  caxis[4][3]
  boundary_rxy[]
  offset
```

### 3.2 变换矩阵

平面板变换矩阵定义为：

```text
float caxis[4][3]
```

含义如下：

- `caxis[0] = u`
- `caxis[1] = v`
- `caxis[2] = w`
- `caxis[3] = o`

其中：

- `u, v, w` 为局部坐标系三个方向向量
- `o` 为局部坐标系原点在全局坐标系中的位置

该矩阵用于局部坐标与全局坐标之间的转换。

### 3.3 边界线

平面板只输入一条基准边界曲线：

```text
boundary_rxy[]
```

约定如下：

- 该边界曲线中的所有实际几何点必须共面。
- 该边界曲线使用 `rxy` 编码。
- 对于一条完整边界线，按第 `2` 章的头元素和段定义规则解释。

### 3.4 偏移

平面板只提供一条边界曲线，另一条配对边界通过偏移得到。

```text
offset: float
```

约定如下：

- `offset` 表示从基准边界到配对边界的偏移距离。
- 偏移方向由边界点顺序和局部坐标系共同确定。
- 当前规范只定义单一偏移值，不定义双向偏移。

## 4. 曲面板定义

当前阶段，曲面板定义为多个曲面组成的集合。

每个曲面由三角面片表示，最终由这些曲面计算得到所有边界曲线信息。

### 4.1 曲面板结构

```text
SurfacePanel
  surfaces[]
```

### 4.2 单个曲面结构

```text
SurfacePatch
  vertices[]
  triangles[]
```

推荐最小表达如下：

```text
vertices[]  = [[x, y, z], ...]
triangles[] = [[i0, i1, i2], ...]
```

约定如下：

- `vertices` 为全局坐标系下的顶点数组。
- `triangles` 为三角面片顶点索引。
- 每个曲面由自身的三角面片集合描述。
- 曲面板的边界曲线不作为主输入字段直接提供，而是由曲面三角面片计算得到。

### 4.3 边界计算结果

曲面板需要从三角面片集合中计算得到全部边界曲线信息。

当前规范只要求“能得到边界曲线”，不限制具体算法实现。

## 5. 返回值定义

返回值定义为多个曲线段。

每个曲线段由一组 `rxyz` 点和一个切线方向信息组成。

### 5.1 返回结构

```text
WeldCurveResult
  segments[]
```

```text
CurveSegment
  points_rxyz[]
  tangent
```

### 5.2 曲线段点集

```text
points_rxyz[]
```

约定如下：

- 每个曲线段使用 `rxyz` 编码。
- 第 `0` 项仍为头元素。
- 实际几何点从第 `1` 项开始。
- 对于实际几何点 `i`，第 `i` 项的 `r` 按第 `2` 章规则解释。

### 5.3 切线方向

每个曲线段还需要记录一个切线方向。

推荐最小表达如下：

```text
tangent
  point_index
  direction[3]
```

含义如下：

- `point_index`：该切线对应的曲线点索引
- `direction[3]`：该点处的切线方向向量，按全局坐标系表达

约定如下：

- 默认情况下，`point_index` 取当前曲线段的终点。
- 若业务需要，也可以指定为曲线段中的其他点。
- `direction` 应与该点处曲线走向一致。

## 6. 示例

### 6.1 平面板边界 `rxy`

```text
[
  [4, 0, 0],
  [0, 0, 0],
  [3, 10, 0],
  [0, 20, 5]
]
```

解释：

- 第 `0` 项的 `r = 4`，表示该数组共使用 4 项。
- 第 `1 -> 2` 段为直线，因为第 `1` 项的 `r = 0`。
- 第 `2 -> 3` 段为圆弧，因为第 `2` 项的 `r = 3`。

### 6.2 返回曲线段 `rxyz`

```text
segment.points_rxyz = [
  [5, 0, 0, 0],
  [0, 100, 20, 5],
  [8, 120, 20, 5],
  [0, 140, 35, 5],
  [2, 160, 40, 5]
]
```

解释：

- 第 `0` 项的 `r = 5`，表示该数组共使用 5 项。
- 第 `1 -> 2` 段为直线。
- 第 `2 -> 3` 段为半径 `8` 的圆弧。
- 第 `4` 项的 `r = 2`，表示该位置存在截断或断开标记。
